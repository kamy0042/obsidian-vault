# **この達成基準は、どうなっていたらクリアと言えるのか？**

デザイナー

- 収録済の音声のみ、映像のみのコンテンツの伝える情報を、すべての利用者が入手できるようになっていること
    - 視覚的なコンテンツを知覚するのが困難な利用者の役に立つ。
        - 支援技術が、テキストによる代替を音声で読み上げる、視覚的に提示する、又は点字に変換することが可能になる。
    - 音声情報を理解するのが困難な利用者の役に立つ
        - テキストによる提示を読むことができる。
- 収録済の音声のみ、映像のみのコンテンツに対して下記に示す適切な代替コンテンツが提供されている
    - 音声のみ：コンテンツに含まれるすべての逐語的な情報（喝采、笑い、聴衆からの質問、誰が話しているかなど）が正しい時系列順でテキストに書き起こされている
        - 例）演説を録音した音声にテキストの書き起こしが提供されている
    - 映像のみ：映像の内容がその映像を視聴しなくても理解できるように音声で説明がある、またはその説明がテキストに書き起こされている
        - 例）無音映画に、映像の動きを説明している音声トラックがある

## **重要ワード**

デザイナー エンジニア

- 音声のみ
    - 演説を録音した音声など
- 映像のみ
    - 無声映画のような映像など
- 収録済み
    - ライブではないもの
- 時間依存メディアに対する代替コンテンツ
    - 時間依存メディア
        - 時間の経過によって変化するメディア。映画やテレビなど、時間にそって進行する時間軸を持っている
    - 代替コンテンツ
        - [1.1.1 非テキストコンテンツ［A］](https://chatwork.atlassian.net/l/cp/RPvtQdoy) 参照

## **例外**

デザイナー エンジニア

- その音声又は映像が、あるテキストの代替として提供されているものであり、それが明示されている場合を除く
- 音声情報がない映像に対し代替として提供されている音声に対しては、テキストによる代替は必要ない
    - 例）無声映画の代替として提供されている音声解説にキャプションを付与する必要はない

# **どう実装したらこの達成基準を守れるか？**

エンジニア

- 収録済みの「音声」しか含まないコンテンツの場合
    - 音声のみの時間依存メディアに対する代替コンテンツを提供する
        - 音声コンテンツと同じストーリーを伝えて同じ情報を提示するドキュメントを作成する
        - tips: 台本やアウトラインを用意してコンテンツを作成してあるのであれば、それを手始めにするのがよい
- 収録済みの「映像」しか含まないコンテンツの場合
    - 重要な映像コンテンツを説明する音声を提供する
    - 映像のみの時間依存メディアに対する代替コンテンツを提供する
        - 収録済の映像しか含まないコンテンツと同じストーリーを伝えて同じ情報を提示するドキュメントを作成する。<u>この達成方法において、そのドキュメントはコンテンツの長い説明としての役割を果たし、提示の一部である風景、動き、表情などの説明だけでなく重要な情報のすべてを含んでいる。</u>
            - めちゃんこ大変じゃない？？？？

> 木工品の組み立て方を紹介するアニメーションがある。音声はないが、アニメーションにはプロセス中の各ステップの順番を示す番号があり、矢印とピクチャーインピクチャーによってどのように組み立てていくのかが示されている。また、正しく組み立てなかった場合にはどうなるのかを示す短いアニメーションも提供されている。映像しか含まないコンテンツを特定するテキストによる代替には、「パン入れの組み立て方の映像 (テキストによる説明あり)」と書かれていて、映像のテキストによる説明では、その映像にある各ステップの完全なテキストによる説明が提供されている。

## **具体的なマークアップ方法例**

エンジニア

オープンキャプションとクローズドキャプションの2種類の方法があります

> 動画に画像として埋め込まれているのが「オープン」、プレーヤーの機能でキャプション用の別データを重ねているのが「クローズド」です。　https://techblog.yahoo.co.jp/entry/2021121930233808/

### 音声や映像しか含まないコンテンツのすぐ後、提供されている代替コンテンツのリンクを置く

- [達成方法1](https://waic.jp/translations/WCAG21/Techniques/general/G158) / [達成方法2](https://waic.jp/translations/WCAG21/Techniques/general/G166)
- 音声しか含まないコンテンツを特定するテキストによる代替には、「エピソード 42: Zap バージョン 12 (テキストのトランスクリプトあり)」と書かれていて、そのトランスクリプトへのリンクが、音声しか含まないコンテンツのすぐ後に提供されている。

```plain text
<a href="../video/marslanding.mp4"><br >
<a href="Mars_landing_audio.mp3">Audio description of "Mars Landing"</a>
```

