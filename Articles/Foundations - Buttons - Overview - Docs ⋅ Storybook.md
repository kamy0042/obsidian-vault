# **Buttons**

# ボタン概要

Chatworkで扱うボタンは、大きく分けて3種類です。

1. 枠や背景色を持つ、最も一般的な「ボタン」らしい形状のボタン
2. 枠や背景色を持たない、テキストのみのボタン
3. アイコンだけで意味を表せるボタン

ボタンのラベルに機能アイコンを添えることも可能ですが、アイコンのみのボタンとは別物として定義しています。

それぞれのボタンのバリエーションやスタイルについては、それぞれのドキュメントを参照してください。

種類は3つですが、画面上での使い方は次項のように定義しています。

# ボタンの使い方

### **強度（強調度）**

ボタンは、種類とは別に、強度（強調度）を判断基準として用意しています。 以下の関係性と照らし、どのボタンを利用すべきかはデザイナー自身で決めてください。

「強」「並」「弱」の3つの強度を想定しています。

図と強度の関係は以下の通りです。

4. 強
    - 最も重要
    - 画面上での頻出度は、少ない
5. 並
    - 一般的なボタン
    - 常識的な個数で利用
6. 弱
    - 重要度的に弱い
    - 画面上、いくらでも利用可能

強度の強いものは出現回数は低く、強度の弱いものは出現回数が高い、という関係性となります。

### **強度と種類の相関**

先述の種類と強度の関係は、

7. 強
    1. 主要機能を図式化したアイコンボタン
    2. プライマリーカラーの背景付きボタン
8. 並
    3. プライマリーカラー以外背景付きボタン
9. 弱
    4. テキストボタン
    5. テキストボタンをスペースの関係で省略したアイコンボタン

としており、上位のものは、より画面上の頻出度は少なくなり（ここ一番の見せ場に利用する）、下位のものほど好き自由に利用可能と判断できます。

# 適切なボタンの選択

基本的な考え方は、[ボタンの利用方針](https://chatwork.atlassian.net/l/cp/14chXwXB)を参照してください。

上記より1点だけ引用すると、基本はDefaultボタンを使うこと、と定められています。

### **ボタンの選択に迷う場面**

- どのスタイル（種類）をあてるべきか
- Dangerボタンを利用していいか
- Disableにできるボタンか

などが該当します。

- 参考リンク
    - リンクかボタンか？に迷ったら[ボタンとリンクの使い分けについての方針](https://chatwork.atlassian.net/l/cp/WoAjyDXU)
    - disableにするかどうか？は[フォームのボタンをdisableにするかどうかの判断軸](https://chatwork.atlassian.net/l/cp/x8c36D72)

### **ボタンの種類（スタイル）の選択基準**

- 選択に対し優劣を付ける場合には、上に記載されている強度と種類の相関をもとに判断して選択してください
- Dangerスタイルは、破壊的な行為を行う場合にユーザーに注意を促す意味で利用してください
    - なお、破壊的な行為については以下の各方針を参考にしてください
        - [データ破棄、ステータス変更によるエラー防止についての方針](https://chatwork.atlassian.net/l/cp/Qtbu3PsK)
    - 更に、破壊的な行為は簡単に起きてはいけないもの、と考えると画面内にDangerスタイルのボタンが複数配置されることが望ましくない点にご注意ください
- ユーザーに行動を促したいものについては、Primaryスタイルを利用する
    - 誘導の度が過ぎると、UX毀損（ダークパターン）になるので注意してください
        - UX毀損について：[UX毀損を回避する7の基本原則（ガイドライン）](https://chatwork.atlassian.net/l/cp/saP9gWuD)

### **スタイルについての注記**

なお、色でUIに定義された役割を判別できないユーザーがいることに留意ください。

- ボタンのスタイルだけでなく、他の補足文などでも注意を促してください
- ラベリングを含む実装でも、正しく意味が伝わるデザインを採用してください
