# **この達成基準は、どうなっていたらクリアと言えるのか？**

デザイナー

この達成基準は他の基準に比べ、より「なぜ基準が存在しているのか」が重要なものであるため、必ず上の参考ドキュメント（Why）を理解してから進めること。

- <u>動きのある、点滅している、またはスクロールしている</u>情報を、利用者が一時停止、停止、非表示にできる
    - 自動開始し、5秒よりも長く継続し、他のコンテンツと並行提供される場合の基準
- 自動更新する情報を、利用者が一時停止、停止、非表示にできる、または更新頻度を調整できる
    - 自動的に開始し、他のコンテンツと並行提供される場合の基準
- この基準が**クリアできないと干渉につながる**ため、超重要
- 一時停止したコンテンツは、リアルタイムで再開するか、利用者が一時停止したところから再生を続けるかのどちらか
    - 一時停止した後、利用者が一時停止したところから再開することが、コンテンツを読むために一時停止したいと思う利用者にとっては最適であり、コンテンツがリアルタイムのイベント又は状態に関係のないときには最も良い方法
    - 一時停止した後、（一時停止を解除した時に）最新の表示へ移ることが、リアルタイム又は本来の「状態」にある情報にとってよりよいことである
- 「利用者が一時停止するための仕組み」と判断されるためには、利用者に一時停止の手段として提供されつつも、利用者やフォーカスをそこに縛り付けてページが使用できなくなるようなものではない必要がある
    - 利用者がフォーカスしている時だけアニメーションが停止する（そしてフォーカスを解除し次第再開する）ようなものは、その過程でページを使い物にならなくするため「利用者が一時停止するためのメカニズム」とは判断されず、この達成基準も満たさない

- 5秒
    - 5秒は、利用者の注意を引くのに十分な長さであるが、ページを使用するために利用者が必要に応じて待つことができないほど長くはないために選択された
- 「点滅」と「閃光」は同じコンテンツを指すこともある
    - 点滅
        - 利用者の注意を散漫にさせる問題を引き起こすコンテンツを指す
            - 点滅が停止する（又は停止させることができる）限り、短時間であれば許容できる
        - 通常、点滅は1秒間に3回以上の速度で起こらないが、その可能性はある
            - 点滅が1秒間に3回を超える速さで起こる場合、これはまた閃光とみなされるであろう
    - 閃光
        - 1秒間に3回よりも多く、大きさ及び明るさが十分な場合に、光感受性発作を引き起こす恐れのあるコンテンツを指す
            - 1秒間だけであったとしても許容されず、さもなければ光感受性発作を引き起こす恐れがある
            - 光感受性発作は利用者が閃光を停止するよりも速く発生する恐れがあるため、閃光を停止させることも選択肢にはならない

## **例外**

デザイナー エンジニア

- 動き、点滅、またはスクロール／自動更新が<u>必要不可欠な動作の一部</u>である場合
    - 例）コンテンツの読み込み中やそれに類似した状況の一部として表示されるアニメーション
        - すべての利用者に対していかなるインタラクションも発生する可能性がなく、コンテンツ読み込みの進行状況を表示しないことが利用者の混乱を招いたり、動作停止やコンテンツ破損の誤解を生じたりする可能性がある
    - 例）オンライン共同編集ツールでのリアルタイムのドキュメント変更通知
        - 変更をすぐに把握することがコラボレーション効率性向上に寄与する
    - 例）動的なオンラインマップ
        - 移動中のユーザーにとって、最新の地図情報が重要であり、道案内や交通状況を正確に把握するためには自動更新が必要
    - 例）チャットによるリアルタイムコミュニケーション
        - 即座のコミュニケーションが必要な状況で、ユーザーがすぐに新しいメッセージを確認できるようにするため
- 定期的にソフトウェアによって自動的に更新されるコンテンツやストリーム配信コンテンツでは、コンテンツ再生の一時停止と再開の操作の間に、生成または受信される情報を保持または提示する必要はない
    - 技術的に不可能
    - 多くの状況において利用者の混乱を招くことに繋がりかねない
- コンテンツが自動的に更新される際に、コンテンツ制作者が利用者に更新頻度を制御する手段を提供するという選択肢がある場合
- 数秒間だけ自動更新をしてその後に停止するのはほとんど意味がないので、自動更新には5秒という例外はない
- 5秒未満で停止する点滅の場合
    - 5秒未満の点滅は、点滅が引き起こす混乱が最小限にすることができるため対象外
- 全面広告
    - すべての利用者に15秒の広告を閲覧することを要求するが、広告を閲覧することはすべての利用者に対する要求であり、他のコンテンツと同時に表示されていないので、広告を一時停止、停止、又は非表示にするメカニズムを提供する必要はない

# **どう実装したらこの達成基準を守れるか？**

エンジニア

### コンテンツの一時停止 / 停止

- コンテンツを一時停止させて、一時停止させたところから再開できるようにする
    - WCAG に準拠したインタラクティブなコントロール又はキーボードショートカットを介して機能を提供する
    - もしキーボードショートカットを用いるのであれば、ウェブページで利用者に説明する
    - 例：ウェブページの上部に、スクロールするニュースのバナーが表示されている場合
        - Esc キーを押すとスクロールを一時停止できる
        - Esc キーをもう一度押すとスクロールが再開する
- コンテンツをスクロールさせている場合、それを一時停止するメカニズムを提供する
    - スクロールするコンテンツを作成した場合、そのスクロールを停止する手段を提供する
- 動きのあるコンテンツ、点滅するコンテンツ、又は自動更新するコンテンツを停止させるコントロールを提供する
    - コントロールはページの先頭か、動きのあるコンテンツの近くに配置する
    - 複数のコンテンツが存在する場合、同時に停止させても良いし個別にボタンを設けても良い
    - 

### コンテンツの点滅

- そもそも5秒以内に収める
    - 例：セール中の商品を強調するためのアニメーション画像
        - ページの読み込み時に点滅させ、5 秒以内に停止させる
    - GIF画像の場合、下記を調整することで5秒以内に収める
        - アニメーション画像に含まれるフレーム数
        - フレームレート
        - 繰り返しの回数
    - JSの場合はsetTimeout() 関数を用いて、点滅するコンテンツの表示と非表示の状態を切り替えることができる
    - 
- ユーザエージェントによって停止可能なコンテンツを使用する
    - 特定のウェブコンテンツ技術では、ユーザエージェントによって利用者がアニメーションを停止することができる
        - 一般的にはEsc キーを押すことでアニメーションを停止できる
    - これが機能するとされているウェブコンテンツ技術:
        - Graphics Interchange Format (GIF)
        - Animated Portable Network Graphics (APNG)
            - アニメーションするPNG画像
- 点滅するコンテンツのないページを表示させる
    - この場合、コンテンツに差分が生じないようにする
    - 例：ページ内に点滅するテキストが存在する場合
        - ページの最上部にあるリンクをクリックすることで、点滅するテキストが存在しないページを表示させる
        - 点滅するテキストは、目を引くようにスタイリングされたテキストに置き換えられる
