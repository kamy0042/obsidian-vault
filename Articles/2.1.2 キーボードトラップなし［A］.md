# **この達成基準は、どうなっていたらクリアと言えるのか？**

デザイナー

- キーボードインタフェースだけを用いてコンポーネントからフォーカスを外すことが可能にする
    - 修飾キーを伴わない矢印キー、Tab キー、又はフォーカスを外すその他の標準的な方法でフォーカスを外せない場合は、フォーカスを外す方法を利用者に通知しなくてはいけない
- フォーカスを外せなくなることを「キーボードトラップ」という
- この基準が**クリアできないと干渉につながる**ため、超重要
- キーボードインタフェースに依存するユーザー（マウスなどを使わないユーザー／スクリーンリーダーユーザーも含む）をコンテンツに閉じ込めない
    - カレンダーウィジェットをキーボードで操作できる
    - パズルアプレットをTabキーとその他のキーで操作できる
    - モーダルダイアログから抜け出せなくならない

# **どう実装したらこの達成基準を守れるか？**

エンジニア

- コンテンツが同一レイヤーに存在している場合、基本的には tabindex 等を弄らなければ フォーカストラップも起きないはず
- 別レイヤーでコンテンツが開きそこにフォーカスが移る場合（ダイアログ等）
    - コンポーネント内に「閉じる」ボタンを実装する
    - フォーカスを外すためのキーボード操作を実装する
        - その操作の情報をアクセシブルな方法で提供する必要がある
    - `dialog`タグを使う場合の挙動
        - [<dialog>: ダイアログ要素 - HTML: ハイパーテキストマークアップ言語 | MDN](https://developer.mozilla.org/ja/docs/Web/HTML/Element/dialog)
![](https://developer.mozilla.org/favicon-48x48.bc390275e955dacb2e65.png)
            - > `<dialog>` を開くための`HTMLDialogElement.showModal()`を使用すると、最初にネストしたフォーカス可能な要素にフォーカスが設定されます。
            - > 既定では、`showModal()` メソッドによって呼び出された `<dialog>` は、Esc によって閉じることができます
            - フォーカストラップは無さそう
- 同一レイヤーでコンテンツが開きそこにフォーカスが移る場合（ポップアップ等）
    - Tabキーで元のコンテンツに戻ることができればOK
- ページ内の特定の場所であえてフォーカストラップさせる場合（ルームリスト等）
    - 要素をクリックするとそれに対応したコンテンツが開き、そこにフォーカスが移る
    - 独自操作でリストとメインコンテンツ（チャットルーム等）を行き来させる場合、ルームリストの前にヘルプへのアクセスを設置する必要がありそう

## **具体的なマークアップ方法例**

エンジニア

- [https://waic.jp/translations/WCAG21/Techniques/general/G21](https://waic.jp/translations/WCAG21/Techniques/general/G21)
- フォーカストラップの例 [https://zenn.dev/yend724/articles/20220511-pc51v32llyzu8kws#%E3%83%95%E3%82%A9%E3%83%BC%E3%82%AB%E3%82%B9%E5%88%B6%E5%BE%A1](https://zenn.dev/yend724/articles/20220511-pc51v32llyzu8kws#%E3%83%95%E3%82%A9%E3%83%BC%E3%82%AB%E3%82%B9%E5%88%B6%E5%BE%A1)
    - `const handleKeydownDiaogContainer = (e) => { const firstFocusableElement = focusableElements[0]; const lastFocusableElement = focusableElements[focusableElements.length - 1]; if (e.code === "Tab") { if (e.shiftKey) { // Shift + Tab if (document.activeElement === firstFocusableElement) { e.preventDefault(); // ダイアログ内で最初のtabableの要素の時、最後のtabableの要素にフォーカスを移す lastFocusableElement.focus(); } } else { // Tab if (document.activeElement === lastFocusableElement) { e.preventDefault(); // ダイアログ内で最後のtabableの要素の時、最初のtabableの要素にフォーカスを移す firstFocusableElement.focus(); } } }
};
dialog.addEventListener("keydown", handleKeydownDiaogContainer);`
- キーボード操作の場合は keydown イベントに処理を紐づければOK [https://ja.javascript.info/keyboard-events](https://ja.javascript.info/keyboard-events)
    - `// キーボード操作時に何らかの処理を行う例
document.addEventListener('keydown', function(event) { if (event.code == 'KeyZ' && (event.ctrlKey || event.metaKey)) { alert('Undo!') }
});`
- その他の挙動の実装は利用するライブラリ等に依存するため割愛
