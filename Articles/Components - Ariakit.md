[ButtonTrigger an action or event, such as submitting a Form, opening a Dialog, canceling an action, or performing a delete operation in React. This component is based on the WAI-ARIA Button Pattern.](https://ariakit.org/components/button)

[CheckboxSelect one or more options in a list or toggle a single option using a native or custom checkbox in React. This component is based on the WAI-ARIA Checkbox Pattern.](https://ariakit.org/components/checkbox)

[ComboboxFill in a React input field with autocomplete & autosuggest functionalities. Choose from a list of suggested values with full keyboard support. This component is based on the WAI-ARIA Combobox Pattern.](https://ariakit.org/components/combobox)

[DialogOpen a new window that can be either modal or non-modal and optionally rendered in a React portal. This component is based on the WAI-ARIA Dialog Pattern.](https://ariakit.org/components/dialog)

[DisclosureClick a button to either show (expand, open) or hide (collapse, close) a content element in React. This component is based on the WAI-ARIA Disclosure Pattern.](https://ariakit.org/components/disclosure)

[FormSubmit information with accessible interactive controls in React. Take advantage of the browser's built-in validation with screen reader support. This component is based on the WAI-ARIA Form Role.](https://ariakit.org/components/form)

[HeadingAdd automatic hierarchy to your page contents so users can easily navigate them. This component is based on the WAI-ARIA Heading Role.](https://ariakit.org/components/heading)

[HovercardShow a Popover with additional information when users hover over an element.](https://ariakit.org/components/hovercard)

[MenuAccess a set of commands within a dropdown menu. This component is based on the WAI-ARIA Menu Pattern and the WAI-ARIA Menu Button Pattern.](https://ariakit.org/components/menu)

[MenubarRender a visually persistent menu similar to those found near the top of the window in desktop apps. This component is based on the WAI-ARIA Menubar Pattern.](https://ariakit.org/components/menubar)

[PopoverShow a popup dialog positioned relative to an anchor element. This component can be either modal or non-modal and optionally rendered in a React portal.](https://ariakit.org/components/popover)

[RadioChoose one option from a list of choices presented as radio buttons. This component is based on the WAI-ARIA Radio Group Pattern.](https://ariakit.org/components/radio)

[SelectSelect a value from a list of options presented in a dropdown menu, similar to the native HTML select element. This component is based on the WAI-ARIA Combobox Pattern.](https://ariakit.org/components/select)

[TabDisplay one panel of content at a time with a tabbed interface. This component is based on the WAI-ARIA Tabs Pattern.](https://ariakit.org/components/tab)

[ToolbarGroup a set of related controls, reducing the number of tab stops in the keyboard interface. This component is based on the WAI-ARIA Toolbar Pattern.](https://ariakit.org/components/toolbar)

[TooltipDisplay visual information related to an anchor element when the element receives keyboard focus or the mouse hovers over it.](https://ariakit.org/components/tooltip)

[VisuallyHiddenHide an element visually but keep it available for screen readers and other assistive technologies.](https://ariakit.org/components/visually-hidden)

## Abstract components

[CollectionTrack a collection of DOM elements in the exact order they're rendered in the DOM and watch the DOM for any change to their order.](https://ariakit.org/components/collection)

[CommandClick with a mouse or keyboard to trigger an action. This abstract component is based on the WAI-ARIA Command Role.](https://ariakit.org/components/command)

[CompositeProvide a single tab stop on the page and navigate through the focusable descendants with arrow keys. This abstract component is based on the WAI-ARIA Composite Role.](https://ariakit.org/components/composite)

[FocusablePress Tab or click to shift focus to any React element. This abstract component standardizes focus behavior across different browsers.](https://ariakit.org/components/focusable)

[GroupGroup related elements in a generic container that may have a label. This abstract component is based on the WAI-ARIA Group Role.](https://ariakit.org/components/group)
