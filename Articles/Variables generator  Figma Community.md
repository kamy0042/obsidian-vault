Variables generator preview

Generate Color Variables via on canvas palette.

1. Select parent Sections that have Frames or Sections. The parent Section name will be Collection name and child Frame or Section name will be Mode name.

2. Frame require filled layers like Rectangles. Each layer name will be Variable name.
