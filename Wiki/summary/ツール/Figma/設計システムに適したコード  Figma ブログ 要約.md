# 設計システムに適したコード  Figma ブログ 要約

ソース: [[設計システムに適したコード  Figma ブログ]]

Figma による Code Connect（ベータ）の発表記事。
「デザインシステムを作ったが十分に使われていない」という採用（adoption）問題に対し、Dev Mode に自動生成 CSS ではなく実際のデザインシステムのコードスニペットを表示させる仕組みを提供する。
npm（JS/TS）と Swift Package Manager（SwiftUI）で配布され、figma.connect で Figma コンポーネントのプロパティと実コードの Props をマッピングすると、開発者はモックアップをクリックするだけでデザインシステムチームが公開した承認済みコードサンプルを得られる。
コードを新規生成するのではなく既存の承認済みコードを表面化・配布するアプローチであり、「デザインシステムを最も抵抗の少ない道にする」ことで採用と一貫性を高める思想が核にある。
将来的にはデザインとコードの乖離の自動監査、利用状況アナリティクス、コンポーネント更新の承認フローなどへの発展可能性を示唆している。
