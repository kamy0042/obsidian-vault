# ２週間で爆速整備したデザインシステムと運用ルールを公開｜株式会社カウシェ｜note 要約

ソース: [[２週間で爆速整備したデザインシステムと運用ルールを公開｜株式会社カウシェ｜note]]

シェア買いアプリ「カウシェ」のデザイナー Kana Kikuchi 氏が、1人デザイナー時代の「頭の中のデザインシステム」状態から、複数デザイナー参画を機に2週間でデザインシステムと Figma 運用ルールを整備した実践記。
チームでの一貫性担保を目的に、デザインガイドライン・デザイントークン・コンポーネントライブラリの最小構成を定め、Figma はプロダクト別プロジェクト、デザイントークン/OS別コンポーネントのファイル分割、Master/Develop/Released によるバージョン管理構造に再編した。
カラーは6色のブランドカラーに合う Black を Primary に据える構成、テキストは iOS の Dynamic Type 対応、コンポーネントは HIG と Material Design Guidelines に沿って命名・分類し、State の Variant 名も MDG 基準で統一している。
さらに解釈齟齬が起きやすいボタンの Emphasis や配置ルール、アイコン作成ルール（24pt 四方、線2pt 基準など）まで明文化した。
最も大変だったのはコンポーネントの再構成・再接続で1週間を要したが、この一連の整備によりチーム開発が円滑になったと結論づけている。
