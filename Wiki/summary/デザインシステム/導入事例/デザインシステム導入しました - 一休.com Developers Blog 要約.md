# デザインシステム導入しました - 一休.com Developers Blog 要約

ソース: [[デザインシステム導入しました - 一休.com Developers Blog]]

一休.com のデザイナーによる、デザインシステムプロジェクト発足から UI ガイドライン構築までの事例報告。
発端は Yahoo!トラベルリニューアルで「機能は同じだが色が違うだけ」のコンポーネントが乱立し、CTO からデザイナーとエンジニアの連携不足を指摘されたことで、共通言語としてのデザインシステム導入が提案された。
外部から池田拓司氏を講師に迎え、Adobe XD から Figma へ移行した上で、UI ガイドライン作成・実装コンポーネント化・ドキュメント作成の3項目を実施した。
ガイドラインは Guidelines（基本要素）・Master（本番画面のデザインデータ）・Components（汎用パーツ）の3層で構成し、Figma の Variants で一休とヤフトラの差分を可視化した点が特徴。
小粒度コンポーネントの共通化は多くの対話と時間を要したが、フロー確立後はスムーズに進み、2サービスのデザイン品質担保の基盤ができたと結論づけている。
