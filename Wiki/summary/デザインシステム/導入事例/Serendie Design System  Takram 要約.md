# Serendie Design System  Takram 要約

ソース: [[Serendie Design System  Takram]]

Takram が三菱電機の DX 基盤「Serendie」を支えるデザインシステムをデザインから開発まで一気通貫で手がけたプロジェクト紹介。
宇宙から家電まで幅広い事業領域を持つ三菱電機への適応は国内外でも要求水準が高い部類で、エンジニア主導のものづくり文化を踏まえ、デザイン原則のような抽象要素ではなく UI コンポーネントなど効果を実感しやすい具体要素から着手した。
テーミングとマルチデバイス対応を考慮したデザイントークン、汎用 UI コンポーネントと JavaScript 実装、300超のオリジナルアイコンを、Figma API・Variables・Code Connect を活用した Single Source of Truth 構成で構築している。
設計思想のドキュメントを含めほぼすべてを社外公開しており、三菱電機のような伝統的企業体では国内でほぼ例がない——関係会社・協力会社との協業が多いため、誰でもすぐ使える状態が実利につながるという判断である。
プロジェクト初期から運用チームのリーダーを置き「つくる」から「育てる」への移行を組み込んだ点も含め、大企業の 0→1 事例として示唆が多い。
