# ラクマ リブランディングとデザインシステムリニューアル  Rakuten Rakuma Tech Blog 要約

ソース: [[ラクマ リブランディングとデザインシステムリニューアル  Rakuten Rakuma Tech Blog]]

2022年4月のラクマのリブランディングに伴う、テーマカラー変更（Crimson Red 系から Rakuten Blue 系へ）と UI カラー再設計の事例。
新デザインアセットは佐藤可士和氏監修・楽天社内の Rakuten Design Lab 制作で、ロゴもカタカナから Rakuten Sans Rounded のローマ字表記に変わった。
UI の Primary Color を青にする際、text/outlined ボタンが UI Black と見分けづらくなるため、彩度と印象を保ちつつ明度を上げるアクセシビリティ調整を行った。
「青いボタンは CTR が下がるのでは」というステークホルダーの根強い意見に対し、AB テストも UT もできない時間制約の中で「四角いボタンは赤」というシンプルな定義で一貫性を確保した。
Primary Color＝青の世界に赤ボタンが混在する破壊的変更の懸念は、形状で役割を統一することで認知コストを抑え、結果としてリニューアル後の批判はかなり少なかったと振り返る。
