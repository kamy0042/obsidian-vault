# デザインシステムを積み上げた先には何が待っているのか？｜wentz 要約

ソース: [[デザインシステムを積み上げた先には何が待っているのか？｜wentz]]

SmartHR のプロダクトデザイナーが、組織学習の観点から自社デザインシステムへの取り組みを内省的に振り返った記事。
レビュー・モブデザイン定例のトピック数は増加（2023年下期55件）した一方、デザインシステムへのコンテンツ追加 PR は減少（44→36件）しており、議論で結論が出ても一般化・反映が遅れて同じ議論が繰り返される「車輪の再発明」が起きていると診断する。
この状態を Kolb の経験学習モデルで説明し、「一般化・概念化」の遅れが新メンバーの認知負荷増大やプロダクト間の UI 不統一という組織成長の障害につながると警告する。
デザインシステムは銀の弾丸ではなく、使いたい時にすぐ使える状態にしておくことで機会損失を防ぐ長期投資であり、ノウハウの複利を得る「デザインの積立投資」だと位置づける。
処方箋としては、大きく始めるのではなく反映のハードルを下げること——コミット経験者が未経験者を支援して泥臭くモメンタムを作ること——を挙げている。
