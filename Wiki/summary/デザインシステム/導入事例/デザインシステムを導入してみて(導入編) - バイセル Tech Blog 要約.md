# デザインシステムを導入してみて(導入編) - バイセル Tech Blog 要約

ソース: [[デザインシステムを導入してみて(導入編) - バイセル Tech Blog]]

エンジニア約8人・デザイナー1人の体制に成長したプロダクトで、デザインルール不在による UI の不統一と開発効率低下を解消するためにデザインシステムを導入した記事。
取り組みはスタイルガイド作成と UI コンポーネント整理の2本柱。
実装で使われていたカラーコードを全て洗い出すと31バリエーション（モノクロだけで21）あり、11まで削減したほか、Typography のコンポーネント化とMaterial Design Icons への統一・Figma 管理でスタイルを揃えた。
コンポーネントは Figma のマスタコンポーネントを実装の参照元とし、切り出し基準を「ページを跨いで同じデザインのものはコンポーネント化する」と明文化した。
導入の最大の効果は、エンジニアの「よしなに実装」がなくなったことに加え、デザイナーとのコミュニケーションが密になりチーム全体のデザイン意識が高まったことだと結論づけている。
