# DTx事業部のデザイン基盤整備のこれまでとこれから｜kay｜note 要約

ソース: [[DTx事業部のデザイン基盤整備のこれまでとこれから｜kay｜note]]

MICIN のデジタルセラピューティクス（DTx）事業部で、正社員デザイナー1人目として入社した筆者がデザイン基盤を立ち上げた記録。
デザイナーが業務委託中心でタスクベース対応、共通言語なしという状態から、他プロダクトの開発ミーティングへの参加や事業部の知見共有会（Deep Dive）での啓発を通じて下地を作った。
3名体制になってからはアクセシビリティ・ライティング・イラストの3指針を策定し、アクセシビリティは Ameba Accessibility Guidelines を、ライティングは SmartHR Design System を参考に医療独自の観点を加えている。
心臓血管外科手術の患者向けプロダクトのため実患者でのテストが難しく、対象年齢に近い社員の両親にユーザビリティテストを実施してから UI コンポーネントを作成した。
医療機関向けは Chakra UI、患者向けはテストを踏まえた独自コンポーネントと使い分け、体系化前の緩やかな基盤をデザインシステムに育てる途上にあると結んでいる。
