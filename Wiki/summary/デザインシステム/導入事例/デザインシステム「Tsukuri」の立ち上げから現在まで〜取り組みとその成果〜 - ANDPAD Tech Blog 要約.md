# デザインシステム「Tsukuri」の立ち上げから現在まで〜取り組みとその成果〜 - ANDPAD Tech Blog 要約

ソース: [[デザインシステム「Tsukuri」の立ち上げから現在まで〜取り組みとその成果〜 - ANDPAD Tech Blog]]

ANDPAD のデザインシステム「Tsukuri」の立ち上げから約2年をデザイナー視点で振り返った記事。
立ち上げの背景は、言語化されたルールの不足、プロダクトごとの独自ルール・コンポーネントの乱立、新規プロダクト増加による開発コストの雪だるま式増大の3つだった。
プロセスは「基盤づくり（最小必須要件の言語化とデザイントークン再定義）→ コンポーネント作成（完璧を目指さずリリース後修正前提に切り替え）→ 専任エンジニアのアサインによる Storybook 移行などのシステム化 → 勉強会とハンズオンで全デザイナーが更新できる民主化 → 全社総会での目的共有」と段階的に進んだ。
成果として、プロトタイプから実装までの生産性・品質向上、横断的な情報設計を通じたデザイナーのスキル向上に加え、デザインシステム自体が社内アワードのチーム賞を受賞し評価対象になった。
「守るべき法律」と誤解され始めた際に目的や役割を改めて全社共有した点など、浸透フェーズの誤解への対処も示している。
