# IPの世界観に寄り添う、マルチブランドなカラーシステム設計論｜TORAJIRO 要約

ソース: [[IPの世界観に寄り添う、マルチブランドなカラーシステム設計論｜TORAJIRO]]

Gaudiy のホワイトラベル製品 Fanlink で、IP ごとにプライマリカラーとテーマを切り替えるためのカラーシステムを 0 から設計した詳細な記録。
ダークモード対応・WCAG 2.1 準拠・テーマの柔軟な追加・命名の共通言語化を要件に、Radix UI / Mineral UI / Goldman Sachs / Ameba Spindle をリサーチして設計した。
グレースケールに各ステップのターゲットコントラストと役割を定義して「見本」とし、明度の増減幅を山なりにするパターンで全カラースケールへ展開、黄色など Bright Color は前景色を黒文字に切り替える Radix 式のルールで除外せずに組み込んだ。
手作業の設計プロセスは再現性が低すぎたため、後に LCH 色空間ベースのツール Huetone を導入し、知覚可能性と WCAG / APCA コントラストのリアルタイム検証で運用を効率化している。
筆者自身が「ほとんどの場合このプロセスは不要で、既存カラーシステムやジェネレーターが最短最適」と明言しており、マルチブランドという特殊要件がこの複雑さを正当化するという位置づけで読むべき事例。
