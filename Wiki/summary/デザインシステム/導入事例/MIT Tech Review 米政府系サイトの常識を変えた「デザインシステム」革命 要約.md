# MIT Tech Review 米政府系サイトの常識を変えた「デザインシステム」革命 要約

ソース: [[MIT Tech Review 米政府系サイトの常識を変えた「デザインシステム」革命]]

米国政府の公式 Web デザインシステム USWDS（U.S. Web Design System）の成り立ちと成果を紹介する記事。
連邦政府だけで約2万6000の政府系サイトが独自デザインで乱立し、2013年の Healthcare.gov の失敗が改善の必要性を浮き彫りにしたことを受け、2014年にオバマ政権が 18F と米国デジタルサービス（USDS）を設立、両者が2015年に USWDS を構築した。
現在は47の UI コンポーネントがデザイン例・サンプルコード・ガイドライン付きで定義され、94機関・160サイトで使われ、連邦サイトのページビューは年間約11億に達する。
2019年には政府向けオープンソースフォント「Public Sans」も作られ、透明性と市民との協働、そして「必ずしも完璧でなくとも、より良いものを作ろうと努力する」という継続的改善の原則が貫かれている。
デザインシステムを「美しさ」ではなくアクセシビリティと政府への信頼の問題として位置づける点が、公共セクター事例としての核心。
