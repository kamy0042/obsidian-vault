# デザインシステムの成長。そして、これからどう向き合うか - enechain Tech Blog 要約

ソース: [[デザインシステムの成長。そして、これからどう向き合うか - enechain Tech Blog]]

enechain のデザインシステム（Chakra UI ラッパー）の2024年の一年間のアップデートを振り返り、現在のフェーズを分析した記事。
主なアップデートは、新プロダクト「eSquare Live」に合わせたダークモード対応、全コンポーネントへのアクセシビリティガイドライン適用、デザインと実装の「乖離」の定義と許容基準の議論、i18n の内製対応、デザイントークン使用や訳語漏れを機械的に強制する eslint カスタムルール、バレルファイルの自動生成、そしてデザインシステム経由/Chakra UI 直接利用の比率（component-rate）計測の開始。
9ヶ月で約100回だったリリース頻度はコンポーネントとトークンの整備完了に伴い落ち着き、All Hands で会社のロードマップに組み込まれるなど「自分ごと化」も進んだ。
これらを踏まえ、運用開始から1年半でデザインシステムは「創る」フェーズを脱却し「育てる」フェーズに入ったと総括する。
ほぼ全プロダクトへの導入で「まず使われる」は実現したため、今後の価値はプロダクトのフェーズに寄り添った提案と対話、すなわち「長く向き合っていく」ことにあると結論づけている。
