# デザインに関わる全ての人たちでエベレスト登頂を目指すために取り組んでいること｜amishiratori 要約

ソース: [[デザインに関わる全ての人たちでエベレスト登頂を目指すために取り組んでいること｜amishiratori]]

kintone Design System チームリーダーによる SaaS Design Conference 登壇内容の書き起こしで、「運営理念」「ワーキンググループ憲章」の全文も公開している。
「理想の Button ドキュメント」に2ヶ月かかった経験から、最初から完璧なデザインシステムを作るのは「いきなりエベレスト踏破を意気込む」ようなもので、高尾山から少しずつステップアップすべきだと説く。
フォーカス1は利用実績づくりで、既存実装をそのまま切り出して「今」使えるものをジャストインタイムで提供し、利用開始後に理想へ近づける戦略を取った。
フォーカス2は「開発チーム全体で育てる文化」の形成で、Centralized Model から Federated Model へ移行し、デザイン・アクセシビリティ・UXライティングの3ワーキンググループと利用チームエンジニアからの PR 受け入れを整備した。
結果、運営理念公開から半年でコントリビューターは30名超・職能も6種以上に広がり、プロダクトロードマップにデザインシステム投資が記載されるまでになった。
