# Adobe Spectrumのカラーバリエーションを再発明 要約

ソース: [[Adobe Spectrumのカラーバリエーションを再発明]]

Adobe のデザインシステム Spectrum のカラー担当デザイナーが、100 超の製品を支える色システムを Version 6.0 として刷新した 7 ヶ月のプロジェクトを解説する記事。
2013 年以来ほぼ変わっていなかった色を、HSL から知覚均等色空間 CIECAM02-UCS (CAM02) ベースに移行し、WCAG コントラスト比と知覚コントラストの違い、Stevens' Power Law、Bezold–Brücke shift といった科学的知見を適用して再設計した。
ターゲットコントラスト比を各テーマの利用可能コントラストに対する割合として計算することで、単一の適応型テーマから light / dark / darkest の 3 テーマを生成できる仕組みにした。
各色 14 段階の tint / shade を用意し、700 / 900 インデックスで WCAG の 3:1 / 4.5:1 コントラストを保証するガードレール、および base / layer 1 / layer 2 によるレイヤリングの仕組みを導入した。
自社 OSS ツール Leonardo を同時進化させながら開発し、結果としてアクセシブルで Adobe ブランドに合った、静的スウォッチではなく制約から色を生成するアダプティブなカラーパレットを実現したと結論づけている。
