# ペパボのデザインシステムのドキュメントを公開します - Pepabo Tech Portal 要約

ソース: [[ペパボのデザインシステムのドキュメントを公開します - Pepabo Tech Portal]]

GMOペパボがマルチブランド戦略の下で開発した共通基盤デザインシステム「Inhouse」のドキュメント公開記事。
公開デザインシステムの多くがプロダクト機能に寄るのに対し、ペパボのデザインはコミュニケーション領域にも及ぶため内製が必要であり、Inhouse をデザインランゲージ、コンポーネントライブラリをパターンランゲージと位置づけている。
ブランドごとに上書き可能なトークン群「Flavor」を採用し、Value Token と Semantic Token の2階建て構造で差し替えやすさを確保、Inhouse 本体は個性のない「ふつう」のプロトタイプに徹する原則を敷く。
また、あらゆるサイズをタイポグラフィ（16px/24px の行高基準）から導出するタイポグラフィファーストを採り、調和数列でバーティカルリズムの揃う文字と行間の組み合わせを事前計算している。
デザインシステムを業務効率化に留めず、新規事業への挑戦とデザイン経営を支える資産と位置づけて締めくくる。
