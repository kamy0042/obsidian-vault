# Building a Design System for a Live Product The Challenges Nobody Talks About 要約

ソース: [[Building a Design System for a Live Product The Challenges Nobody Talks About]]

グリーンフィールドを前提とする事例記事と異なり、稼働中プロダクトへのデザインシステム導入で語られない4つの課題を挙げる。
本番環境に17種のグレーを見つけた経験から、インベントリ監査は技術作業ではなく外交であり、「この混乱を見ろ」ではなく「一緒に単純化しよう」と枠づけるべきだと説く。
導入は時速70マイルで走行中の車のタイヤ交換であり、新旧コンポーネントが並存する中途半端なハイブリッド期が事例記事の想定より遥かに長く続くことを受け入れよと言う。
経営の支持は一度得て終わりではなく四半期ごとに請求書が届くものであり、「ボタンをリファクタした」を「機能をより速く・バグ少なく・一貫したブランドで出せる」に翻訳し続けることが生存スキルになる。
良いシステムが静かに死ぬのはガバナンスであり、貢献の審査方法と例外への断り方を設計する組織デザインこそが本当の仕事だと結論づける。
