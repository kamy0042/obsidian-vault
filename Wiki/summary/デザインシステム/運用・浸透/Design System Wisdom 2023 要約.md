# Design System Wisdom 2023 要約

ソース: [[Design System Wisdom 2023]]

Astro UX Design System のリード開発者を3年務めた Cianfrani による教訓集。
大前提（Prime Directive）は「ユーザーが使いたいものではなく、使うことを強制されるものを作っている」という自覚で、思慮深いホストとして振る舞い、他社DSの判断を過大評価するなと説く。
構築面では「すべてをコンポーネント化するな」（セレクトメニューやデータテーブルは OSS に勝てない）、API は柔軟性と使いやすさの2つのノブの調整であり、悪い API の決定は紙傷のように蓄積してシステムを壊すとする。
育成面では定期的な剪定、年1回の「なぜやっているのか」の再確認、NPM ダウンロード数などの計測、特定コンポーネントへの要望集中は API の柔軟性不足のサインという運用知見を挙げる。
ドキュメントはデザインアセットやコードより重要で、AI を訓練できる品質を目指せとし、バージョニングでは「誰もアップグレードで見返りがなければ動かない」ため codemod や移行ガイドへの投資と breaking change の明文化を求める。
