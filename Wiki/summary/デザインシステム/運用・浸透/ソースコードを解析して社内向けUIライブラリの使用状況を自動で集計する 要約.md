# ソースコードを解析して社内向けUIライブラリの使用状況を自動で集計する 要約

ソース: [[ソースコードを解析して社内向けUIライブラリの使用状況を自動で集計する]]

プレイドのデザインエンジニア安田氏（yuheiy）が、KARTE のデザインシステム「Sour」の React ライブラリ sour-react の使用状況を全プロダクトのソースコード解析で自動集計する仕組みを解説する記事。
ライブラリが浸透するほど破壊的変更の影響把握が難しくなりバージョンアップが滞る問題に対し、TypeScript の Compiler API で named imports を抽出し、モジュール別・プロダクト別の参照箇所を GitHub Actions で毎朝自動集計してマークダウン出力する。
実際に、特定プロダクトでしか使われない特殊モジュールの削除を、使用実態を正確に把握した上で確信を持って安全に行えたという活用例を挙げる。
仕組みは internal-library-reference-stats として OSS 公開されており、テンプレートリポジトリから誰でも導入できる。
