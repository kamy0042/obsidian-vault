# How to create a Lean Design System 🙌🏼  by Freehand by InVision  Inside Design  Medium 要約

ソース: [[How to create a Lean Design System 🙌🏼  by Freehand by InVision  Inside Design  Medium]]

InVision の Mark Boyes-Smith が、先行投資の余裕がないチーム向けにリーン思考をデザインシステムに適用する4原則を示す記事。
パレートの法則に基づき「最も影響の大きい20%の仕事」に投資を集中させることで、DS の便益（信頼できる唯一の情報源、開発の高速化、一貫した体験、共通言語）を最小コストで引き出すことを狙う。
原則は (1) Find the fires: UX 監査で最も深刻な不整合を特定、(2) Don't reinvent the wheel: Airbnb や Atlassian など先行 DS の構造をつまみ食いしてアーキテクチャを設計、(3) Best of basics: 基盤（色・タイポ・スペーシング）とデザイントークンを最優先で磨き、利用チームが基盤を継承して実験できるようにする、(4) Win friends not battles: ゲートキーパーになるのではなく、コンポーネントを利用チームからクラウドソースする。
「DS はプロセスよりパートナーシップによってこそ速く、適切に進化する」というのが核心の主張。
