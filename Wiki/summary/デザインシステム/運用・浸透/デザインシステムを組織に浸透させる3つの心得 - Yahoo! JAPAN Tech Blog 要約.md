# デザインシステムを組織に浸透させる3つの心得 - Yahoo! JAPAN Tech Blog 要約

ソース: [[デザインシステムを組織に浸透させる3つの心得 - Yahoo! JAPAN Tech Blog]]

ヤフーの水野直氏が、DS.INSIGHT を支える DS.DESIGN SYSTEM の大規模改修経験から、デザインシステムの難しさは構築より「運用し機能させ続けること」にあるとして3つの心得を示す記事。
第一に、タックマンモデルで組織のフェーズを診断し（外部公開された洗練システムは散会期、自チームは混乱期）、完璧さよりフェーズに合った役割定義に立ち返ること。
第二に、改修完了後に PM から「何も変わってないじゃないか」と言われた失敗を通じ、デザインシステムはプロジェクトではなく「もう1つのプロダクト」であり、コンウェイの法則どおり組織のコミュニケーションの歪みがシステムに現れるため、リソース配分とメリットを提案段階から丁寧に繰り返し訴え続けるべきだとする。
第三に、正しさだけでは人は動かないため、討論・議論・対話・雑談を使い分け、相手の主張に耳を傾けた上で信念を持って伝え続ける対話の姿勢を説く。
デザインシステムは開発プロセスに組み込みコミュニケーションを展開して初めて機能する、が全体の結論。
