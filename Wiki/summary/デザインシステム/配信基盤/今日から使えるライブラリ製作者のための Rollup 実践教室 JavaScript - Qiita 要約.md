# 今日から使えるライブラリ製作者のための Rollup 実践教室 JavaScript - Qiita 要約

ソース: [[今日から使えるライブラリ製作者のための Rollup 実践教室 JavaScript - Qiita]]

ライブラリ製作者向けに Rollup の実践的な設定レシピを紹介する記事（クリップは記事後半のみの部分クリップ）。
ES2015 用の出力ファイルと package.json の module エントリを揃えることを基本として押さえる。
プロダクションビルドでは uglify プラグインで minify し、開発時は istanbul プラグインでソースマップを扱うなど、環境変数でプラグイン構成を出し分ける。
UMD モジュール出力では name（自身のパッケージのグローバル名）と output.globals（依存パッケージ名と UMD グローバル名の対応）の指定が必要になる。
UMD 版が存在しない依存は自身のバンドルに含めなければならない点が注意点である。
