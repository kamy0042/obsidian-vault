# S3 バケットとローカルのディレクトリを同期する AWS CLI の aws s3 sync コマンドの初歩的な使い方のメモ。 - 全力で怠けたい 要約

ソース: [[S3 バケットとローカルのディレクトリを同期する AWS CLI の aws s3 sync コマンドの初歩的な使い方のメモ。 - 全力で怠けたい]]

`aws s3 sync` コマンドの基本的な使い方をまとめた実行例付きメモ。
`aws s3 sync <同期元> <同期先>` の形式で、ローカル→S3・S3→ローカル・S3 プレフィックス間の3方向すべての同期に使える。
主要オプションは以下の通り。

- `--dryrun`: 実際には転送せず操作予定を表示する
- `--delete`: 同期元にないファイルを同期先から削除する（デフォルトでは削除しない）
- `--exclude` / `--include`: パターンで同期対象を除外・再包含する（`'*a.txt'` のようにワイルドカード指定で全階層に適用）

デフォルトでは削除が同期されない点と、exclude のパターンが相対パス基準である点が実務上のつまずきどころ。
なおクリップにはブログの性質上、iTerm2 コピーモードや id / groups コマンドのメモなど無関係なエントリが後半に結合されている。
