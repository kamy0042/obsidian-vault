# S3を使った静的サイト構築のあるある - Qiita 要約

ソース: [[S3を使った静的サイト構築のあるある - Qiita]]

S3 の Web ホスティングでよく必要になる定番設定をまとめた記事。
S3 は Basic 認証をサポートしないため、ステージング環境の限定公開はバケットポリシーの IP アドレス制限で代替し、エラーページだけは NotIpAddress 条件で全員に許可して不親切な 403 画面を避ける。
404 エラーページは ErrorDocument 指定に加え、RoutingRules を書くことで「同一バケット内の 404.html へリダイレクト」「別ホストへリダイレクト」「別ホストの特定ページへリダイレクト」を出し分けられる。
ReplaceKeyWith は要求された URI と設定した URL を置換する仕組みで、301 リダイレクト後に 200 でコンテンツが返ることを curl で確認している。
2014年頃の「書き途中」記事ながら、S3 静的ホスティングのアクセス制御とエラーハンドリングの基本パターンを押さえている。
