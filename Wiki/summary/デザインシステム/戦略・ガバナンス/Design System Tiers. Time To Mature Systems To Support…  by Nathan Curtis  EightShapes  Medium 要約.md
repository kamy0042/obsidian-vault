# Design System Tiers. Time To Mature Systems To Support…  by Nathan Curtis  EightShapes  Medium 要約

ソース: [[Design System Tiers. Time To Mature Systems To Support…  by Nathan Curtis  EightShapes  Medium]]

Nathan Curtis が2019年に発表した、デザインシステムを「最高品質の core だけの単一階層」ではなく柔軟な tier（階層）構造として設計する提案。
全員に関係する最高品質の core の下に、事業部門内（within）と部門横断（across）の tier を設け、実験的な機能を共有・育成して core へ昇格させる経路を作る。
tier ごとに品質基準を明確化し（上位ほど厳格）、名前空間は中央でキュレーションして衝突を防ぎ、ドキュメントでも tier を明示すべきと説く。
権限モデルは「可視性は最大に、編集権は限定的に」とし、システムチームはチーム間の共有投資を結びつけるマッチメーカーの役割を担う。
結論として、tier は貢献（contribution）を「実験から全社利用への昇格」として語るための共通言語と受け皿になる。
