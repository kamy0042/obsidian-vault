# A Global Design System  Brad Frost 要約

ソース: [[A Global Design System  Brad Frost]]

Atomic Design の提唱者 Brad Frost が、世界中の Web デザイナー・開発者が使える共通 UI コンポーネントライブラリ「Global Design System」の創設を呼びかけた提言記事。
組織ごとのデザインシステムは組織内の重複作業を減らしたが、結果として全組織がアコーディオンやデートピッカーなど同じコモディティ的コンポーネントを重複して作り続ける「メタデザインシステム問題」が生じ、しかも上位100万サイトで1ページ平均50件のアクセシビリティエラーが検出されるなど品質も低いままだと指摘する。
解決策として、HTML の上のレイヤーに位置する、見た目とテクノロジーに依存しない Web Components ベースの共通ライブラリを提案し、テーマ適用可能・アクセシブル・国際化対応・拡張可能であることを要件に挙げる。
Material Design や Bootstrap 等の既存ライブラリは特定組織の目的と固有の見た目を伴う点で不適であり、運営主体としては W3C のような標準化団体が適切で、Open UI プロジェクトの成果も活用できるとする。
実現すれば世界のデザイナー・開発者の数百万時間を節約し Web 全体の品質とアクセシビリティを向上させ、各デザインシステムチームはコンポーネント製造ではなくデザイン言語の構築や組織固有の高付加価値な仕事に集中できると結論づけている。
