# The Design System Ecosystem  Brad Frost 要約

ソース: [[The Design System Ecosystem  Brad Frost]]

Brad Frost が、大規模組織における成熟したデザインシステムの全体像を「コアデザインシステム／技術別実装／レシピ／スマートコンポーネント／プロダクト」の5層のレイヤーケーキとして描いた記事。
コア層はトークン・アイコン・UIコンポーネント・リファレンスサイトで構成され、Web の実装には相互運用性の高い Web Components を強く推奨する。
レシピ層はコアの部品を組み合わせたプロダクト固有のコンポーネント群で、デザインシステムチームのボトルネックと燃え尽きを防ぐ「圧力逃がし弁」として機能し、優れたレシピはコアへ「昇格」できる。
スマートコンポーネント層はダムなUI部品にビジネスロジックやサービス接続を包み、プロダクト開発者に即戦力の部品を提供する。
ただしコア以外の層はすべてオプションであり、Gall の法則に従って必要が生じたときにだけ層を足すべきで、最終的にシステムを成立させるのはアセットではなく人と人の関係だと結ぶ。
