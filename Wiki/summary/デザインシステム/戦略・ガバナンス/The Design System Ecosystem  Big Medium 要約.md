# The Design System Ecosystem  Big Medium 要約

ソース: [[The Design System Ecosystem  Big Medium]]

Brad Frost が、大規模組織のデザインシステムを「コアデザインシステム／技術別実装／レシピ／スマートコンポーネント／プロダクト」の5層エコシステムとして解説した記事の Big Medium 掲載版。
コア層はデザイントークン・アイコン・UIコンポーネント・リファレンスサイトで構成され、Web 実装にはフレームワーク非依存の Web Components を推奨する。
レシピ層はプロダクト固有の合成コンポーネントにチームの自律性を与えてコアチームのボトルネックを防ぎ、スマートコンポーネント層はロジック付きの即戦力部品を提供する。
コア以外の層はオプションであり、Gall の法則に従い必要が生じたときにだけ複雑さを足すべきで、システムを支えるのは最終的にアセットではなく人の関係だと結ぶ。
