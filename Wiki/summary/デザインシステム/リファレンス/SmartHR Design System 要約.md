# SmartHR Design System 要約

ソース: [[SmartHR Design System]]

SmartHR が全面公開しているデザインシステム smarthr.design のトップページのクリップ。
「すべての人によりよい体験を届けるためのデザインシステム」を掲げ、SmartHR に関わる人なら誰でも利用・参加できるオープンな運営を特徴とする。
コンテンツは3本柱で構成される。

- アクセシビリティ — 「だれでも」使える・コミュニケーションできるための考え方、ガイドラインとチェックツール
- プロダクト — スケーラブルで一貫性のある設計のためのガイドラインと、OSS「SmartHR UI」の利用方法
- コミュニケーション — マーケティング・セールス・カスタマーサクセスで使う一貫したサービスコミュニケーションのアイテムとガイドライン

情報をオープンにする理由を「車輪の再発明を減らし、社会に良い影響をもたらすため」と明言しており、プロダクト UI にとどまらず全社の表現基準を束ねる公開デザインシステムの代表例となっている。
