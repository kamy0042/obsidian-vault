# 日本・海外のデザインシステム総まとめ【52事例＋α】｜akane 要約

ソース: [[日本・海外のデザインシステム総まとめ【52事例＋α】｜akane]]

公開されているデザインシステムを国別に52事例集めた note のリンク集（2024年2月時点、随時更新方針）。
日本（SmartHR / Spindle / vibes / Inhouse / Ubie Vitals / デジタル庁ほか17事例）、アメリカ20事例（USWDS / Spectrum / Carbon / Primer / Polaris 等）、イギリス6事例（GOV.UK / BBC GEL 等）、北欧4事例ほか欧州・中国までを網羅する。
各事例は URL に加えて「Text input / Textfield」系コンポーネントのスクリーンショットを添える構成で、同一パターンの各社比較がしやすい。
デザインシステム本体は非公開だが構築過程の記事があるもの（SMBC / メルカリ / Yahoo! JAPAN SAYA / Wantedly 等9事例）と、参考記事のリンク一覧も付属する。
事例探索の入口として有用だが、クリップは冒頭部分（日本事例の前半）が欠けており、リンク切れの可能性もあるため一次情報の確認が必要。
