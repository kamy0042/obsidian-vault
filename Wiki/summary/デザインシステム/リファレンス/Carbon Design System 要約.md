# Carbon Design System 要約

ソース: [[Carbon Design System]]

Carbon は IBM が公開しているオープンソースのデザインシステムで、プロダクトとデジタル体験の構築を目的としている。
IBM Design Language を基盤に、動作するコード、デザインツールとリソース、ヒューマンインターフェースガイドライン、コントリビューターコミュニティの4要素で構成される。
開発者向けには React・Angular・Vue・Svelte・Web Components・Vanilla の各コンポーネントライブラリが、デザイナー向けには Figma キットと Sketch キットが提供されている。
公式サイトでは Next.js 13 対応チュートリアルの更新、Carbon for React Native の導入、Figma variables と統合テーマライブラリの発表など、継続的な拡張が紹介されている。
フィードバックやデザイン提案などのコントリビューションを広く受け入れる姿勢を打ち出している。
