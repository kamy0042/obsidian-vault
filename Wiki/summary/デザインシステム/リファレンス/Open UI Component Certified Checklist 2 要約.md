# Open UI Component Certified Checklist 2 要約

ソース: [[Open UI Component Certified Checklist 2]]（画像のみの重複クリップ「Open UI Component Certified Checklist」「同 3」は 2026-07-26 に削除済み）

W3C の Open UI コミュニティグループによる、コンポーネント提案の品質を認定するためのチェックリスト（Google Docs のドラフト）。
コンポーネント作者がまず自己レビューし、その後2名以上のコミュニティメンバーが検証するという運用を想定している。
チェック領域は Accessibility / Privacy and Security / Internationalization / Performance / Style and Structure / W3C Intellectual Property / Blueprint の7分類＋雑則で構成される。
具体項目には「全フォーカス可能要素のキーボード操作」「AT でのアクセシブルネーム検証」「不要なネットワーク・ストレージ利用の禁止」「unsafe-eval の不使用」「未 minify で 100kb 以下」などがあり、社内デザインシステムのコンポーネント品質基準の下敷きとしても流用できる。
