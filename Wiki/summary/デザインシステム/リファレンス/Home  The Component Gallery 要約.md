# Home  The Component Gallery 要約

ソース: [[Home  The Component Gallery]]（重複クリップ: [[Home  The Component Gallery 1]], [[Home  The Component Gallery 1 2]], [[Home  The Component Gallery 2]]）

コンポーネントベースの UI を作る人のためのリファレンスサイト「The Component Gallery」のホームページ。
世界中のデザインシステムから収集した実例をコンポーネント種別ごとに横断整理しており、Button は135例、Accordion は101例など、1つの UI パターンを複数システムの実装で比較できる。
各コンポーネントには定義文と別名（Accordion に対する Collapse / Disclosure / Expander 等）が付き、命名調査の起点として使える。
デザインシステム側の索引も持ち、PatternFly・Gestalt・Base Web などを採用技術（React / Vue / Sass 等）と特徴（Open source / Usage guidelines / Accessibility 等）のファセットで一覧できる。
Vault には2023年12月と2024年10月のクリップが計4件あるが、いずれも同一サイトのホームのスナップショットである。
