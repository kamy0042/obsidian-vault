# Imperavi 要約

ソース: [[Imperavi]]

UI 関連のツールと書籍を提供する Imperavi のサイトトップのクリップ。
自社のデザインシステムを「フレームワークとして設計されたデザインシステム」と位置づけ、目的や要件に応じたカスタマイズ・変更のしやすさを特徴として打ち出している。
書籍として「Web Interface Handbook」（UI 作成の原則とベストプラクティス）、「Designing Design Systems」（機能するデザインシステムの作り方）、オンラインブック「User Interface Typography」を公開している。
プロダクトとしてはハイブリッド型テキストエディタ「Redactor X」、メールテンプレート編集の「Revolvapp」、ブロックスタイルの「Article Editor」を提供する。
デザインシステム・UI タイポグラフィ・エディタ実装を横断する制作者向けリソースハブとして参照できる。
