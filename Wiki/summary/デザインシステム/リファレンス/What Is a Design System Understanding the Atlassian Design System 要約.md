# What Is a Design System Understanding the Atlassian Design System 要約

ソース: [[What Is a Design System Understanding the Atlassian Design System]]

Atlassian Design System を題材にデザインシステムの基礎を解説する入門連載の第1回。
デザインシステムを「一貫性のある体験をスケールさせるための原則・ファウンデーション・再利用可能コンポーネント・パターンの集合」であり、デザイナーと開発者の共有言語だと定義する。
50人の開発者が微妙に異なるボタンを量産する例を挙げ、重複コード・保守コスト増・ブランド更新の困難といった非一貫性の実害を説明する。
Atlassian はこれをファウンデーション（色・タイポグラフィ・スペーシング・エレベーション・デザイントークン）、コンポーネント、パターンの3層で解決していると整理する。
Jira と Confluence の AI チャット体験が共有パターンにより一貫している例を示し、デザインシステムはコンポーネント集ではなく共有言語だと結論づける。
