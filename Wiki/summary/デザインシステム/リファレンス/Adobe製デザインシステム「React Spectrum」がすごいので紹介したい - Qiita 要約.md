# Adobe製デザインシステム「React Spectrum」がすごいので紹介したい - Qiita 要約

ソース: [[Adobe製デザインシステム「React Spectrum」がすごいので紹介したい - Qiita]]

Adobe がリリースしたデザインシステム react-spectrum を、リリース直後の興奮とともに紹介する Qiita 記事。
筆者が最も評価するのは UI とロジックを完全に分離し、ロジック部分を再利用可能にした設計で、「実際にすごいのはロジック部分」だと述べる。
react-aria はカスタム Hooks でデバイス間の挙動差を吸収し（onClick を onPress に統一するなど）、react-stately は DatePicker や Table など複雑なコンポーネントのロジックを UI 非依存で提供する。
これらを借りれば、自分・自社のデザインシステムでもアクセシビリティの高いコンポーネントを効率よく実装できる。
筆者は業務のデザインシステムで多様なプラットフォーム対応のロジック作りに苦労してきた経験から、その改修に役立つと期待して締めくくっている。
