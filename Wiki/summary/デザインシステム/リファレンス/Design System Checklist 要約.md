# Design System Checklist 要約

ソース: [[Design System Checklist]]

デザインシステムの計画・構築・成長を支援するオープンソースのチェックリストサイト designsystemchecklist.com のクリップ。
チェック項目は4カテゴリで構成される。

- Design language — 10項目
- Foundations — 26項目
- Core components — 166項目
- Maintenance — 28項目

計230項目でデザイン言語の定義から基盤・コンポーネント・保守運用までを網羅し、自チームのデザインシステムの抜け漏れを点検する監査ツールとして使える。
運営チームはこのチェックリストを使って Figma / React 向けの商用デザインシステム「Reshaped」を構築しており、その実践が裏付けになっている。
