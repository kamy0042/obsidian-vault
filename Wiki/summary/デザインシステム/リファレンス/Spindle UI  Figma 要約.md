# Spindle UI  Figma 要約

ソース: [[Spindle UI  Figma]]

CyberAgent が Figma Community で公開している「Spindle UI」ファイルの説明ページのクリップ。
Spindle UI は Ameba のデザインシステム「Spindle」に内包された UI ライブラリの総称で、「Amebaらしさ」を一貫して体現するための必要十分な共通コンポーネント群としてブランド指針に準拠する。
Figma ファイルにはコンポーネント本体に加えて遵守すべきガイドラインが同梱され、デザイナーが Guideline を参照しつつ Sticker Sheet から Instance を複製して各ファイルへ持ち運ぶ使い方を中心に設計されている。
利用者はコメント機能を通じて元コンポーネントの開発者に直接質問でき、各コンポーネントに至った経緯や根拠を知ることができる。
公開の狙いはデザインシステムへの「納得」と「共感」を作ることにあり、ドキュメントとしての閲覧性とコンポーネントの扱いやすさを重視した利用体験を追求していると述べる。
