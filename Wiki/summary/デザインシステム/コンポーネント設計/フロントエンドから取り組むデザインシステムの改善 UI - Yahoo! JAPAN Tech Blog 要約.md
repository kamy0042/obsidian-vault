# フロントエンドから取り組むデザインシステムの改善 UI - Yahoo! JAPAN Tech Blog 要約

ソース: [[フロントエンドから取り組むデザインシステムの改善 UI - Yahoo! JAPAN Tech Blog]]

ヤフー社内の横断デザインシステム「Riff」のフロントエンド開発・運用改善の紹介記事。
Riff はスタイルガイド・Design Token・Sketch 用 Design Kit・React ライブラリの4プロダクト構成で、狩野モデルの「当たり前品質」を担保する位置づけ。
運用改善として、Storybook カタログと Playroom デモ環境、reg-suit によるビジュアルリグレッションテスト、全テキスト×背景色のコントラスト比（4.5:1）を機械検証する一覧表、CI からの集計スクリプトによるコンポーネント利用数の定量測定を実践している。
最大の教訓は「デザインシステムは利用者の環境やアーキテクチャを制限しない独立したプロダクトであるべき」という点。
CSS-in-JS（treat）がビルド環境を要求して導入に2週間かかった反省から、ビルド済みスタイルを配布する Sass へ移行し、アイコンもデザインツール非依存の SVG 生成機能（Riff-Icon）として分離した。
