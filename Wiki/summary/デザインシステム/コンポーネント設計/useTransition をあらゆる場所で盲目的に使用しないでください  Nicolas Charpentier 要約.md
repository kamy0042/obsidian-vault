# useTransition をあらゆる場所で盲目的に使用しないでください  Nicolas Charpentier 要約

ソース: [[useTransition をあらゆる場所で盲目的に使用しないでください  Nicolas Charpentier]]

React の useTransition を万能な UX 改善策として推奨する風潮への反論記事。
React 公式ドキュメントのタブ切替例ですら、isPending 表示中に旧タブがアクティブなまま残る体験は良くないと批判し、本来はタブ自体を高優先度で即時更新し、コンテンツ描画を後追いさせるべきだと主張する。
落とし穴として、transition は緊急レンダーと並行レンダーの二重レンダーをスケジュールするため高コストなコンポーネントのメモ化が必須なこと、制御されたインプットには使えないこと、全状態更新をラップすると緊急のフィードバックまで遅延することを挙げる。
代替案として、次のイベントループまで描画を遅らせる Delay コンポーネントで React に制御を返し、その内部で必要な場合のみ useTransition を併用する「タブ＝重要・コンテナ＝高優先・コンテンツ＝低優先」の優先度設計を提示する。
さらに `<Activity>` によるプリロードや隠しマウントも有望な選択肢とし、ルーティングライブラリ等の必要な場面以外で盲目的に使うべきではないと結論づける。
