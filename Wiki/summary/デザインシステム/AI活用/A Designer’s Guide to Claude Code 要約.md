# A Designer’s Guide to Claude Code 要約

ソース: [[A Designer’s Guide to Claude Code]]

プロダクトデザイナーの Katherine Yeh が、非エンジニアの視点から Claude Code を用いた AI デザインワークフローの整理法を解説した記事。
Claude を「優秀だが自社を知らない新人デザイナー」に見立て、必要なのは知識と能力を与える Skill、外部ツールと接続する MCP サーバー、作業場所である環境という3概念だけだと説く。
環境は2つ使い分け、批評・調査・ドキュメント作成などの「思考」は Cowork（デスクトップアプリ）で、Figma への実描画は localhost 接続の制約から Terminal の Claude Code で行う。
核心はスキルをデザインシステムのように3層で構造化することで、レイヤー1に参照スキル（デザイン原則・コンポーネント仕様などの知識）、レイヤー2に能力スキル（デザインレビューや生成などのワークフロー）、レイヤー3にツールコネクタ（MCP）を置き、依存関係を明示することでスキルの重複や混乱を防ぐ。
著者は1ヶ月でターミナル未経験からこの体制を構築でき、重要なのは完璧なツールチェーンではなく体系的な出発点を持つことだと結論づけている。
