# Figma Dev Mode MCPサーバーの実践的な要点 要約

ソース: [[Figma Dev Mode MCPサーバーの実践的な要点]]

Figma Dev Mode MCP サーバーを実際に使う際の注意点とポイントを、公式ドキュメントの補足として簡潔にまとめた記事。
利用には Dev またはフルシートのライセンスと Figma デスクトップアプリの起動が必須で、CI/CD 環境では使えない。
MCP サーバーはレイヤー構造をそのまま返すのではなく、Figma がデザインをコードに変換した結果を返す仕組みであるため、Flexbox を正確に表現するには Auto Layout の丁寧な設定が必要になる。
Code Connect を使うとコードベース内のコンポーネントを忠実に使ってくれる一方、実装がデザインとずれていれば生成される UI も当然ずれる。
コード品質にこだわらなければページ丸ごと生成でも再現度は意外と高く、プロトタイピングやペライチの実装に向くと評価している。
