# MCP でアクセシビリティ（ WCAG 2.2 準拠）レビューを爆速自動化： Figmaアノテーション生成 要約

ソース: [[MCP でアクセシビリティ（ WCAG 2.2 準拠）レビューを爆速自動化： Figmaアノテーション生成]]

キカガクが、属人化しがちなデザインレビューと WCAG 2.2 準拠チェックの負荷という課題に対し、MCP でアクセシビリティレビューを自動化した検証記事。
Figma Dev Mode MCP でコンポーネントの画像・コード・色変数を取得し、WCAG 2.2 の基準（知覚可能の「判別可能」）に基づきコントラスト比を自動計算、課題を緊急・重要・推奨の優先度に分類して改善提案を作成する。
最後に html.to.design MCP でレビュー結果を優先度付きアノテーションとして Figma キャンバスに自動配置し、検証から分析・伝達までの自動化を実現した。
算出されたコントラスト比は Stark プラグインとほぼ一致したが、透明度使用時には微差があり、最終的にはチェックツールを併用して人間が整合性を確認すべきと述べる。
確認コスト削減・客観的数値による品質担保・再現性・見落とし防止の効果があり、今後は CI/CD 統合やデザインシステム全体の一括検証への拡張を展望している。
