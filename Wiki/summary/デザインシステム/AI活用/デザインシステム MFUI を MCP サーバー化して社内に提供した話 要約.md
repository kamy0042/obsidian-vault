# デザインシステム MFUI を MCP サーバー化して社内に提供した話 要約

ソース: [[デザインシステム MFUI を MCP サーバー化して社内に提供した話]]

マネーフォワードのデザインシステム MFUI のコンポーネント情報を AI コーディングアシスタントに提供する MCP サーバー「mfui-developer-mcp」の実装解説。
コンポーネント一覧・アイコン一覧・指定コンポーネントの全ファイル取得という3つのツールを提供し、ソースコードそのものをコンテキストに含めて返す素朴な設計をとる。
配布は npm 公開ではなく「利用者が MFUI リポジトリをクローンしてビルドする」方式を選び、セキュリティ懸念の低減とデザインシステムへのコントリビュート促進を理由に挙げる。
Framelink Figma MCP と組み合わせれば、Figma デザインから MFUI コンポーネントを使った実装提案を受けることもできる。
課題はソースコード全文返却によるトークンサイズの肥大で、ドキュメント化による削減とそのメンテナンス負荷のトレードオフを慎重に見極めるとし、将来的には開発者だけでなくデザイナーや PdM にも役立つツールを目指すと結ぶ。
