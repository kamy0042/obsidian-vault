# Design Systems Are About to Start Thinking 要約

ソース: [[Design Systems Are About to Start Thinking]]

現在のデザインシステムは「よく整理されたファイリングキャビネット」であり、答えは中にあるのに自分から語りかけてこない受動的な保管庫だと指摘するオピニオン記事。
次世代の「agentic（エージェント型）」デザインシステムは、作りたいものを自然言語で記述すると文脈（プロダクトの目的・スタイル・a11y ルール・過去の解決策）を理解して具体的な提案を返し、レスポンシブ展開・空状態・仕様書作成などの反復作業を肩代わりする。
コンポーネントは「どう見えるか」だけでなく、重要度・リスク・確認の要否といったプロダクト理解を運ぶ存在になる。
Figma や Slack や個人の記憶に散在する設計知識が一箇所に集約され、テストやレビューのフィードバックで学習し続ける点も価値とする。
これはデザイナーの置き換えではなく、Auto Layout やコンポーネント化と同じく退屈な作業を減らして人間の判断が要る仕事に時間を移す進化であり、デザインシステムの価値は常にコンポーネント数ではなく蓄積された知識と決定にあったと結論づける。
