# PJ-Aurora：メルカリにおけるUI生成・評価の取り組み  メルカリエンジニアリング 要約

ソース: [[PJ-Aurora：メルカリにおけるUI生成・評価の取り組み  メルカリエンジニアリング]]

メルカリ・メルペイが CXO と共に推進する、生成 AI によるものづくり変革プロジェクト「PJ-Aurora」の紹介記事。
Google の ADK による Agentic Workflow として、アイデアを構造化プロンプトに変換するコンセプトリファイン Agent と、MCP 経由でメルカリのデザインシステム参照画像・アセットを確認しながら HTML を生成する UI 生成 Agent を実装している。
UI 生成自体は外部サービスが群雄割拠しており最終的に内製に固執しない一方、デザインシステムを AI が読める状態にすること、デザインのアイデンティティを言語化・構造化すること、AI 前提のワークフローを発明することこそが組織の資産であり差別化要因になると主張する。
並行して、品質評価観点と仮想ペルソナによる UI/UX 評価の概念実証にも着手し、Browser Use などで画面操作をさせてフィードバックを得る仕組みを検証中である。
技術の進歩とともに「何を作るか、どう作るか、仕事の仕方はどう変わるか」という本質的な問いへの向き合いが一層重要になると締めくくっている。
