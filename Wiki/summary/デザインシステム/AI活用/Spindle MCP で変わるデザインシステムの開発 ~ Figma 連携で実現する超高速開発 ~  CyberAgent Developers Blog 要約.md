# Spindle MCP で変わるデザインシステムの開発 ~ Figma 連携で実現する超高速開発 ~  CyberAgent Developers Blog 要約

ソース: [[Spindle MCP で変わるデザインシステムの開発 ~ Figma 連携で実現する超高速開発 ~  CyberAgent Developers Blog]]

Ameba デザインシステム Spindle に特化した Spindle MCP Server の仕組みと成果を紹介する記事。
コンポーネント・デザイントークン・アイコンに加え、アクセシビリティチェックリストや Design Doc テンプレートまで MCP ツールとして提供し、Storybook や README などの既存ファイルをローカルで読むだけの構造のため「普段の活動がそのまま MCP になる」協調性が特長である。
体感値でデザイン約1.5倍・ドキュメント作成約5倍・開発約3倍の速度向上が見込まれ、Figma Dev Mode MCP で生成したコードを Spindle 実装へ置き換える連携では、手動27分の実装が2分半で完了し AI 活用で10倍のスピードアップの可能性を試算している。
開発で得た知見として、法則性のない構造や暗黙知に基づく実装は LLM がつまずくため明文化が必要で、Storybook のサンプルコードなど既存ドキュメントが生成精度を支えることを挙げる。
MCP サーバー開発を通じて口頭共有されていた暗黙知が可視化されたことも副次的メリットだったと述べている。
