# Cursor Visual Editor でデザイナーがスタイル修正から PR作成まで行う開発フロー - ROXX開発者ブログ 要約

ソース: [[Cursor Visual Editor でデザイナーがスタイル修正から PR作成まで行う開発フロー - ROXX開発者ブログ]]

ROXX が Cursor Visual Editor を導入し、スタイル修正から Pull Request 作成までをデザイナーのみで完結する体制を作った事例。
従来はエンジニアとデザイナー間のチェック依頼と修正のラリーが多く、1px 単位の調整のためにコンテキストスイッチが発生していた。
デザイナー向けの Rules を用意し、ブランチ切り替え・スタイル修正 PR 作成・レビューコメント対応をそれぞれ Slash Command 化することで、非エンジニアでも git 操作を含むフローを回せるようにした。
Figma に近い操作感と自然言語指示で修正できるためデザイナーはすぐ馴染み、コードベース上での仕様確認やデザイン壁打ちという副次効果もあった。
初回の環境構築が最大のネックであるため、スタイルチェックが繰り返し発生するプロジェクトで特に有効と結論づけている。
