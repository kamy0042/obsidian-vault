# AIネイティブを目指した「これまで」と「これから」｜agu  relay（リレイ） 要約

ソース: [[AIネイティブを目指した「これまで」と「これから」｜agu  relay（リレイ）]]

relay Design System を約3か月で構築した実践記であり、AIネイティブ化の目的を単なる効率化ではなく、「当たり前品質」を仕組みに移して人にしか作れない価値へ時間を返すことに置く。
狩野モデルを使い、DESIGN.md の譲れない原則を当たり前品質、迷ったときの判断基準を一元的品質として整理し、コードリポジトリを正本、Figmaを探索と最終調整の場に変えた。
Tailwind CSS v4ベースのフレームワーク非依存CSSとして既存サイトへ段階導入し、MCPは導入手順・コンポーネント・トークン・原則・アクセシビリティ等を「目次→詳細」で渡し、instructions と初回セットアップ導線で参照漏れを防ぐ。
WCAG 2.2の各基準とコンポーネントについてデザインシステム・プロダクト・AIの責任分界を明記し、実サイトの置換ではAI支援により約150箇所のアクセシビリティ改善を行ったと報告する。
ハードコードやアクセシビリティはhooksで決定的に遮断し、コンポーネント選定や表現品質は固定課題のevalsで採点する一方、魅力的品質の創出と、成熟した品質をルールへ移す判断は人が担うと結論づける。
