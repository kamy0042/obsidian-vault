# 【MCPのトリセツ 6】Figma MCP：デザインとコードを効率的に連携 要約

ソース: [[【MCPのトリセツ 6】Figma MCP：デザインとコードを効率的に連携]]

MCP 入門シリーズの第6回として、コミュニティ製の figma-developer-mcp を使った Figma MCP の導入と活用例を解説するチュートリアル記事。
Figma のパーソナルアクセストークンを取得し、Claude Desktop や Cursor 等の設定ファイルに追記するだけの3ステップでセットアップできる。
AI が Figma のデザインデータへ直接アクセスすることで、色・サイズ・フォント等の正確な数値取得、React コンポーネントへの変換、デザイントークンの一括抽出などが可能になる。
大規模ファイルではノード ID を指定して特定要素だけを取得するのが効率的で、CVA を使ったバリアント実装やデザイン仕様書の自動生成、デザインシステムからの逸脱チェックといった実践例も紹介する。
デザインデータを直接取得することで情報の見落としや解釈の誤りを減らし、デザインとコードの連携を効率化できると結論づけている。
