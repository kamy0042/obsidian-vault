# Design Systems 2.0 The source of truth is the code. 要約

ソース: [[Design Systems 2.0 The source of truth is the code.]]

Figma、文書、コード、ガイドラインに同じシステムを複製すると必然的にドリフトするため、AIに複数の写しを同期させる発想自体を改めるべきだと論じる。
実際に利用者へ届くのは稼働するコードであり、そのコードをブラウザ上の視覚的キャンバスとしてデザイナーと開発者が共同編集する構成を唯一の真実源として提案する。
AIで原則と制約を定義し、エンジニアがトークン・配信・版管理の基盤を作り、その上でデザイナーが実装そのものを設計する流れを示す。
ドキュメントもパッケージとともに機械可読な契約として配布し、出荷物とは別の人間向け説明が古くなる問題を避ける。
結論は、AIを旧来のハンドオフ工程へ追加するのではなく、コード・キャンバス・文書・リリースが一つの生きた成果物を共有する工程へ再設計することである。
