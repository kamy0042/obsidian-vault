# 【Figma × Cursor】AI連携でデザインレビューを自動化する全手順【動画連動解説】｜梅本 周作 - ajike 要約

ソース: [[【Figma × Cursor】AI連携でデザインレビューを自動化する全手順【動画連動解説】｜梅本 周作 - ajike]]

Figma 公式の Dev Mode MCP と有志開発の「Cursor Talk to Figma」プラグインを組み合わせ、デザインレビューを自動化する手順の解説記事。
Cursor に Figma のフレーム URL を渡してレビューを依頼すると、AI が MCP 経由でデザイン情報を読み取り、UI/UX 観点の評価と改善案を生成する。
さらに生成された改善案を Talk to Figma プラグイン経由で Figma 上にアノテーション（注釈）として自動で書き込み、カテゴリ分けまで指示できる。
Dev Mode MCP の利用には Figma の有料プランが必要で、Talk to Figma 側は WebSocket サーバーの起動など多少の技術知識を要する。
著者は、この連携によりレビューに客観的基準を導入でき、属人的なアドバイスを減らしてフィードバックの品質と一貫性を向上させられたと結論づけている。
