# Your Component Library Is Not a Design System 要約

ソース: [[Your Component Library Is Not a Design System]]

個々の部品が正しく揃っていても、部品間の関係と文脈ごとの振る舞いを定めなければ、製品全体は一貫した体験にならないと論じる。
コンポーネントは名詞、システムは動詞であり、再利用可能な部品よりも、複数の部品が特定の課題を解くパターンを整備する必要がある。
デザインシステムは原則・基盤・コンポーネント・パターン・ガバナンスの5層から成り、多くの組織は中央の二層だけを作っていると整理する。
部品だけの思考は判断のやり直し、振る舞いの不整合、ユーザーの信頼低下、チーム間の局所最適を生むため、頻出する一つの行為から文脈別パターンを明文化すべきだと提案する。
結論として、デザインシステムの本体はライブラリではなく、製品を一つの意思で作られたように感じさせる関係・規則・意思決定の集合である。
