# How to create a color palette for design systems  Blog 要約

ソース: [[How to create a color palette for design systems  Blog]]

imperavi（Superkube Design System 作者）による、デザインシステム向けカラーパレット構築の実践手法。
まずブランド色・黒白グレー・ダークテーマ用の「ナイトカラー」・5種のステート色（active / focus / negative / positive / notice）・セカンダリ・プロダクト固有色などのベースカラーを確定し、あらゆる背景で破綻しないよう白黒の透明度スケールも用意する。
ティント・シェード生成はアルゴリズムが不透明なプラグインに頼らず、ベースカラーに透明度を重ねる自作の「カラービルダー」（Figma で公開）で行うことで、値の数を自由に決められ、どの色でも同じインデックスが同じ役割になる再現性を確保する。
パレットの名前は primary などのセマンティックではなく blue / red といった色名で付け、セマンティックカラーやトークンはこのパレットを土台に別途構築する。
経験則として1スケール15値が最適（10未満はダークテーマに不足、15超は複雑化）で、数値インデックスは拡張余地のある10刻みを推奨し、必ず実コンポーネントでコントラストを検証せよと結ぶ。
