# デザイントークンって何？｜seya｜note 要約

ソース: [[デザイントークンって何？｜seya｜note]]

日本語情報が少なかったデザイントークンを、W3C（Design Tokens Community Group）の定義から出発して体系的にまとめた入門解説。
提唱者 Jina の「デザイントークンは方法論であり、ただ変数化することではない」という言葉を軸に、意義を「一貫性のある UI を作る基礎」「標準化」「コードとの同期（Single Source of Truth）」の3つに整理する。
トークンは「値を表すもの（Global）」と「意味を持ったもの（Alias）」の2階層に分けるのが主流で、Alias の参照先を差し替えるだけでダークモードなどの Theming が可能になる利点を説明する。
定義対象のプロパティとして色・タイポグラフィ・角丸・space・size・shadow・animation・z-index を列挙し、プロダクトごとに一貫性を持たせたいものから優先度を付けて定義すればよいとする。
実運用では Figma Tokens（現 Tokens Studio）プラグインでトークンを定義し、JSON エクスポートと GitHub 連携でフロントエンドのコードへ同期するパイプラインを組むことで真価が発揮されると結論づける。
