# Design tokens need more than semantics 要約

ソース: [[Design tokens need more than semantics]]

セマンティックトークンを、色のようにエンドユーザーへ意味を伝える層だけと捉えると、スペーシングやサイズの設計では実務者の思考と噛み合わない。
Spectrum の調査では、デザイナーとエンジニアは余白を「関係の強弱」ではなく、ラベルと入力欄の間隔やコンテナ内のパディングといった構築上の用途で説明していた。
そこで同チームは、トークンとコンポーネントの中間に繰り返し現れるラベル・説明・画像・操作要素などの構成を「structural templates」として定義した。
構造・可変点・合成関係を先に定めると、必要なスペーシング等のトークンは後から導出できるが、既存コンポーネントの再設計が必要になる場合もある。
結論として、セマンティクスには利用者へ意味を伝えるものと UI の構築方法を表すものがあり、反復構造を第一級の設計概念にすることが再利用性と拡張性を高める。
