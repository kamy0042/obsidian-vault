# The Anatomy of a Design Token 要約

ソース: [[The Anatomy of a Design Token]]

Jonas Duri がデザイントークンの構成要素を Name / Type / Meta / Data の4つに分解して解説する入門記事。
Apple の「Space Gray」を例に、名前と実際の値を疎結合にすることで、名前を変えずに値を進化させられることがトークンの本質だと示す。
名前は最も重要な要素であり、用途がすぐ伝わる示唆的でユニークな命名が求められ、Type は「色は塗れるがアニメーション時間には使えない」といった使い方の予測可能なインターフェースを規定する。
Data は RGBA のような技術非依存フォーマットで持ち、web には rem、iOS にはネイティブ形式など、変換ツールでプラットフォーム別に出力すべきとする。
結論として、生トークンは Git リポジトリや NPM パッケージなど中央の場所に公開し、各アプリケーションが変換して使える体制を推奨している。
