# デザイントークン  プロダクト  SmartHR Design System 要約

ソース: [[デザイントークン  プロダクト  SmartHR Design System]]

SmartHR Design System 公式サイトのデザイントークン解説ページ。
トークンの効用として、デザイナー・エンジニアへの低レイヤーな統一言語の提供、スケーラブルで一貫性のあるプロダクト設計、ハードコードを減らし変更に強い開発、の3点を挙げる。
提供するトークンは2種類で、もっとも低レイヤーで原子的な値を持つ「プリミティブトークン」と、特定のコンテキストに関連し意図した目的を伝える「セマンティクストークン」に分類される。
プリミティブトークンは十分な値と増減が容易な名前空間を持たせることが望ましく、セマンティクストークンは単一の意図を持つ値が複数の場所に現れる場合に使うとする。
参考文献として Salesforce Lightning と Adobe Spectrum のトークン定義を挙げており、2層構成の簡潔なリファレンスとなっている。
