# デザインシステムのためのカラーパレットの作成：改訂版 要約

ソース: [[デザインシステムのためのカラーパレットの作成：改訂版]]

imperavi の Alex Butenko による、デザインシステム向けカラーパレット構築手法の改訂版解説。
UI デザインでは状態表現やダークテーマのために多数の tints / shades が必然的に必要になり（ミニマルに見える Apple HIG も実際は各色のフルパレットを持つ）、恐れずに広いパレットを体系化すべきだと説く。
良いパレットの要件として、十分な色数・出発点となるベースカラー・アクセシビリティ・自動化・アルゴリズムを自分で完全にコントロールできることの5つを挙げる。
中核となる「Color Builder」は、白背景への透明度でティント、ダーク背景（Night 色）への透明度でシェードを生成する自作の仕組みで、プラグインのブラックボックスなアルゴリズムに依存せず任意のベースカラーから数秒でパレットを作れる。
ライト/ダークテーマで対応する値が a4 / b4 のように鏡映しになる命名規則により、テーマ間の対応判断も自動化される。
著者は17値のパレットを標準とし、実コンポーネントでのテストとコントラスト確認を必須の仕上げとしている。
