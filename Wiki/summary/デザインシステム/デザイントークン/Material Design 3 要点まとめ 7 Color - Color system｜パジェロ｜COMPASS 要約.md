# Material Design 3 要点まとめ 7 Color - Color system｜パジェロ｜COMPASS 要約

ソース: [[Material Design 3 要点まとめ 7 Color - Color system｜パジェロ｜COMPASS]]

Material Design 3 ガイドラインの Color system 章を日本語で要約した解説記事。
M3 のカラーシステムは配色を固定値ではなく「相対的な色調のまとまり」と捉える動的な設計で、5つのキーカラー（プライマリ / セカンダリ / ターシャリ / ニュートラル / ニュートラルバリアント）それぞれから白黒を含む13段階のトーンパレットを生成する。
UI へは16進数値を直接割り当てず、トーンから選ばれたカラーロール（プライマリ / オンプライマリ / プライマリコンテナ / オンプライマリコンテナ等）をトークンでマッピングするため、パレットが変わっても体系的に色を更新できる。
サーフェスの高度（Elevation）はプライマリカラーの半透明オーバーレイの不透明度で表現され、アウトラインは 3:1 のコントラスト比を持つ色と装飾用バリアントを使い分ける。
13トーンの値（0〜100）は「40以上離れれば 3:1、50以上離れれば 4.5:1」のコントラスト比を保証するよう配分されており、動的テーマ変更やダークモード切替でもデフォルトでアクセシブルな配色が維持される仕組みになっている。
