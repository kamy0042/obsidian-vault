# Vol.436 - Frontend Weekly Tokyo 要約

ソース: [[Vol.436 - Frontend Weekly Tokyo]]

フロントエンド関連記事を紹介する週刊ニュースレターの2023年12月号。
筆頭は大規模組織における成熟したエンドツーエンドのデザインシステム論で、デザインシステムとプロダクトは互いに影響し合う循環関係にあり、多くのレイヤーはオプションなのでシンプルに始めて実際のニーズに応じてエコシステムを段階的に複雑化すべきとする。
CSS 変数の命名についても取り上げ、意味のある名前・ケース規約・接頭辞/接尾辞・コメント・ドキュメント化を推奨する。
そのほか、フレームワーク非依存の Web 標準としての Web Components（shadow DOM は最終手段とする実用論）、フォームは単一列レイアウトが完了率を高めるという Baymard Institute の調査などを紹介する。
デザイントークンそのものの深掘りではなく、トークン・変数命名・デザインシステム設計を横断的に俯瞰できるリソース集という位置づけ。
