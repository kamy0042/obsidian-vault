# Design tokens - Foundations - Atlassian Design System 要約

ソース: [[Design tokens - Foundations - Atlassian Design System]]

Atlassian Design System の Foundations 章にあるデザイントークン公式ドキュメント。
トークンを「小さく反復可能なデザイン決定を表す名前と値のペア」と定義し、`#36B27E` のような生値ではなく `color.icon.success` のような意図ベースの名前で適用することを基本原則とする。
テーマは「トークンの集合を特定の値にマッピングしたもの」であり、文脈と意味で命名されたトークンは1つでライト／ダーク／ホワイトラベルの複数テーマを表現できる。
トークン名は Foundation（color / elevation）→ Property（text / background / border 等）→ Modifier（役割・強調・状態）の3部構成で、名前自体が使い方を記述する。
「色が見た目で一致するからという理由でトークンを選ぶな」という Do/Don't を示し、意図に合ったトークン選択こそがテーマ横断での体験を守ると強調する。
