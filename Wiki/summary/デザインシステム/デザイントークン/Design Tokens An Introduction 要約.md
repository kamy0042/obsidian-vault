# Design Tokens An Introduction 要約

ソース: [[Design Tokens An Introduction]]

Andy Barnes によるデザイントークンの概説記事（Frontend Digest, 2020）。
デザインからコードへのハンドオフに伴う「解釈の推測」を減らす手段としてトークンを位置づけ、技術非依存の小さなスタイリング情報＝コード変数化されたデザイン決定と定義する。
利点として、コード重複の回避・中央更新による無償のスタイル更新・共通言語化・技術スタック移行の容易さ・デザイン側へのオーナーシップ移譲の5点を挙げる。
実装例として Adobe XD でトークン名を検証し、Style Dictionary で JSON から SASS / Swift など各プラットフォーム向け変数を生成、npm パッケージとしてリリースノート付きで配布するワークフローを示す。
デザイナー自身がデザインツール内でトークンをネイティブに扱える体験はまだ未成熟であり、ツールの進化が今後の課題だと締めくくる。
