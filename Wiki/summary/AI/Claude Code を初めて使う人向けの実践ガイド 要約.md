# Claude Code を初めて使う人向けの実践ガイド 要約

ソース: [[Claude Code を初めて使う人向けの実践ガイド]]

医療プラットフォーム HOKUTO のエンジニアが Zenn に書いた、Claude Code を使い始めて3週間の知見をまとめた初心者向け実践ガイド。
設定ファイルの使い分けを整理しており、CLAUDE.md はプロジェクトルートならチーム共有ルール、`.claude/` なら個人のプロジェクトルール、`~/.claude/` なら全プロジェクト共通の個人ルールになると解説している。
目玉は Stop フックで reviewit を起動する設定で、タスク完了時に AI の変更内容を diff ビューでレビューし、指摘事項をまとめてコピペできるようにしている。
フックのスクリプトは git 差分があるときだけ空きポートを探して reviewit を立ち上げる作りになっている。
なお HOKUTO では Devin AI と Claude Code Max プランを全メンバーに配布して生成 AI を積極活用していると紹介されている（クリップの一部は画像のみでテキスト化されていない）。
